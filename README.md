# Ιστοσελίδα Νίκου Ισκή — Next.js

Επαγγελματική ιστοσελίδα στα ελληνικά με Next.js App Router, ξεχωριστές σελίδες υπηρεσιών και έμφαση στο τεχνικό και τοπικό SEO.

## Εκκίνηση τοπικά
1. Εγκαταστήστε Node.js 20.9 ή νεότερο.
2. Εκτελέστε `npm install`.
3. Εκτελέστε `npm run dev`.
4. Ανοίξτε http://localhost:3000.

## Δημοσίευση στο Vercel
1. Ανεβάστε τα περιεχόμενα αυτού του φακέλου στο GitHub repository.
2. Στο Vercel επιλέξτε Import Project και το repository.
3. Το Vercel πρέπει να αναγνωρίσει αυτόματα το Next.js.
4. Αφήστε τις προεπιλεγμένες ρυθμίσεις Build και Output.

## SEO που έχει ενσωματωθεί
- Ελληνικά HTML (`lang="el"`) και περιεχόμενο που αποδίδεται από τον server.
- Ξεχωριστές σελίδες για ΚΕΝΑΚ, πυροπροστασία, ΥΔΕ/ΗΜ μελέτες, CCTV/συστήματα ασφαλείας και ηλεκτρολογικές εργασίες.
- Μοναδικοί τίτλοι, meta descriptions, canonical URLs και Open Graph ανά σελίδα.
- Structured data JSON-LD για ProfessionalService και Service.
- XML sitemap (`/sitemap.xml`) και robots (`/robots.txt`).
- Σημασιολογικές επικεφαλίδες, εσωτερικοί σύνδεσμοι και περιγραφικά URLs.
- Responsive σχεδιασμός και απουσία εξάρτησης από client-side JavaScript για το βασικό περιεχόμενο.
